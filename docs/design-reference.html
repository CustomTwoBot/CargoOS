CargoOS, эталон финального дизайна

Финальная сборка

Эталон вида для вёрстки. Переключай светлую и тёмную тему, состояние до и после ответа ops lead, жми «Проиграть». Полное описание: CARGOOS_DESIGN.md.

  • ЗакрепленоGraphite, Host Grotesk, цифры гротеска без копеек, узкая рейка, крупное At stake с полосой, статусы формой, полосы групп, две строки, цепочка доказательств, строка едет.
  • ПонятностьСветлая тема по умолчанию, простые слова, четыре шага, кнопки с пояснением, стандартный размер, объяснение вопросами, подсказки «?».
  • ПринципСначала понятно, что делать, потом почему, потом детали. Названия групп и главные кнопки остаются как в спеке, команда на них опирается.
